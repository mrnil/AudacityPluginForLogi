### Added

- Buttons for Record, Record New Track, Play/Stop, Stop, Pause, Go to Start/End, Add Label, Undo, Save Project and Zoom In/Out/Fit, driven over Audacity's mod-script-pipe
- Scrub, Zoom and Track Gain dials. Track Gain starts from the selected track's current volume
- Record, play and pause buttons show the transport state, and icons dim while Audacity isn't running
- Supports Loupedeck CT, Live and Live S, and the Logitech MX Creative Console, on Windows and macOS
